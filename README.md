# TrendScope — сайт «Влияние TikTok на стиль одежды»

Одностраничный сайт для научного проекта: опрос с определением стиля,
статистика для админа, раздел про стили и механику трендов.

## Что внутри
- `index.html` — весь сайт (главная, стили с фото, тренды, опрос, админка)
- `images/` — фотографии людей в каждом стиле

## Публикация на GitHub Pages
1. Создайте новый репозиторий на github.com (кнопка New repository).
2. Загрузите в него `index.html` и папку `images` с фотографиями:
   через «Add file → Upload files» или командой:
   ```
   git init
   git add .
   git commit -m "site"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
3. Откройте Settings → Pages → в блоке Build and deployment
   выберите Source: «Deploy from a branch», Branch: main, папка: / (root).
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## Админ-панель
Раздел «Админ» → логин `admin`, пароль `style2026`.
Пароль меняется в коде `index.html` (константа ADM).

## Важные ограничения (честно)
- Данные опроса хранятся в localStorage браузера: статистика собирается
  только с устройства, где проходили опрос. Анонимные прохождения
  не сохраняются вообще (защита приватности).
- Пароль админа лежит в клиентском коде — для реального исследования
  нужна серверная авторизация.
- Чтобы подключить настоящую нейросеть к генерации портрета стиля,
  заполните блок `AI_CONFIG` в начале скрипта в `index.html`.
